# الجدول الأسبوعي

صفحة واحدة (`index.html`) بلا خادم ولا قاعدة بيانات. يكتب المستخدم اسمه ويدخل مباشرة، وتُحفظ أهدافه وسجل أسابيعه على جهازه تحت اسمه.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `weekly-planner`).
2. ارفع الملفين `index.html` و`README.md` إلى الفرع `main`.
3. من Settings ← Pages اختر Deploy from a branch، الفرع `main` والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/weekly-planner/`

## ملاحظات

- البيانات في متصفح الجهاز (localStorage) ولا تنتقل بين الأجهزة. للنقل: من القائمة «تصدير نسخة احتياطية» ثم «استيراد نسخة» في الجهاز الآخر.
- مسح بيانات المتصفح يمسح الأهداف، فيُنصح بتصدير نسخة احتياطية من حين لآخر.
- الدخول بالاسم فقط بلا كلمة مرور: من يعرف الاسم على نفس الجهاز يرى بياناته.
- الحد الأقصى 40 هدفًا لكل اسم.
