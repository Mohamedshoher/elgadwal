# الجدول الأسبوعي

صفحة واحدة (`index.html`) تعمل على GitHub Pages، بحساب (اسم مستخدم وكلمة سر) وقاعدة بيانات Supabase. أهدافك وسجلك تظهر على كل أجهزتك.

## كيف تعمل
- «حساب جديد» ينشئ حسابك، و«دخول» يدخلك من أي جهاز.
- كل تغيير يُحفظ على الجهاز ثم يُرفع تلقائيًا إلى السحابة. وإن انقطع الإنترنت يُرفع عند عودته.
- تُسحب بياناتك عند فتح الصفحة وعند العودة إليها وكل دقيقتين.
- كلمة السر لا تُحفظ نصًّا بل مُشفَّرة (bcrypt)، والجداول مغلقة عن الوصول المباشر وكل شيء يمر عبر دوال تتحقق من جلستك.
- بعد 8 محاولات خاطئة يُقفل الحساب 10 دقائق.

## النشر على GitHub Pages
Settings ← Pages ← Deploy from a branch ← `main` ← `/ (root)`.

## التثبيت كتطبيق
أندرويد/كروم: ⋮ ← تثبيت التطبيق. آيفون/Safari: مشاركة ← إضافة إلى الشاشة الرئيسية. الكمبيوتر: أيقونة التثبيت في شريط العنوان.

## ملاحظات
- استعادة كلمة السر برمز استرجاع (12 حرفًا) يظهر عند إنشاء الحساب، ويُولَّد رمز جديد من أيقونة المفتاح في القائمة. الرمز يُستعمل مرة واحدة، وبعد 5 محاولات خاطئة يُقفل الاسترجاع 30 دقيقة. ضياع الرمز مع نسيان كلمة السر يعني تعيينها يدويًا من لوحة Supabase.
- النسخة المجانية من Supabase تتوقف بعد أسبوع تقريبًا بلا استخدام وتُشغَّل من لوحة Supabase بضغطة.
