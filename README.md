# الجدول الأسبوعي

صفحة واحدة (`index.html`) بلا خادم ولا قاعدة بيانات. يكتب المستخدم اسمه ويدخل مباشرة، وتُحفظ أهدافه وسجل أسابيعه على جهازه تحت اسمه.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `weekly-planner`).
2. ارفع الملفين `index.html` و`README.md` إلى الفرع `main`.
3. من Settings ← Pages اختر Deploy from a branch، الفرع `main` والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/weekly-planner/`

## ربط جوجل شيت (اختياري)

من القائمة الجانبية اضغط «ربط جوجل شيت». تُنشأ في حساب جوجل ورقة «الجدول الأسبوعي - الاسم» بتبويبين (الأهداف، السجل) وتُزامن معها كل التغييرات. من جهاز آخر: ادخل بنفس الاسم واضغط «ربط جوجل شيت» بنفس حساب جوجل فتُحمَّل بياناتك.
- الصلاحية المطلوبة `drive.file` فقط، فلا ترى الصفحة إلا الملف الذي أنشأته.
- في Google Cloud يجب أن يكون `https://mohamedshoher.github.io` ضمن Authorized JavaScript origins، وأن يكون Sheets API وDrive API مفعّلين.
- تنتهي جلسة جوجل بعد ساعة تقريبًا؛ إن لم تُزامن التغييرات اضغط «إعادة الربط» وتُرفع تلقائيًا.

## التثبيت كتطبيق

الصفحة تطبيق ويب قابل للتثبيت (PWA): على أندرويد/كروم قائمة ⋮ ← «تثبيت التطبيق»، وعلى آيفون Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية»، وعلى الكمبيوتر أيقونة التثبيت في شريط العنوان. ويفتح بعد ذلك بدون شريط المتصفح وحتى دون اتصال (تُحفظ التغييرات وتُرفع عند عودة الإنترنت).

## ملاحظات

- البيانات في متصفح الجهاز (localStorage) ولا تنتقل بين الأجهزة. للنقل: من القائمة «تصدير نسخة احتياطية» ثم «استيراد نسخة» في الجهاز الآخر.
- مسح بيانات المتصفح يمسح الأهداف، فيُنصح بتصدير نسخة احتياطية من حين لآخر.
- الدخول بالاسم فقط بلا كلمة مرور: من يعرف الاسم على نفس الجهاز يرى بياناته.
- الحد الأقصى 40 هدفًا لكل اسم.
